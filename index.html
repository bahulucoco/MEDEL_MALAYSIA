Membuka sistem...

Tiada sambungan internet. Sistem MEDEL memerlukan internet untuk memaparkan data terkini.
Buka Sistem MEDEL
Pasang di iPhone / iPad:
1. Buka halaman ini dalam Safari.
2. Tekan butang Kongsi (petak dengan anak panah ke atas).
3. Pilih Add to Home Screen / Tambah ke Skrin Utama.
Pasang di Android:
Tekan menu ⋮ di Chrome, kemudian pilih Install app / Tambah ke skrin utama.
✅ Aplikasi MEDEL telah dipasang. Buka melalui ikon MEDEL di skrin utama.
